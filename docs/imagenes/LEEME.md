# Las imágenes del README

| Archivo | Qué muestra | De dónde salió |
|---|---|---|
| `01-mapa.webp` | el mapa completo, cuatro capas | `pruebas/mirador/capturas.sh` |
| `02-asistente.webp` | el asistente del primer uso | a mano, dentro de Obsidian |
| `03-camino.webp` | el camino entre dos notas | `capturas.sh` |
| `04-vacios.webp` | los vacíos entre temas | `capturas.sh` |
| `05-radial.webp` | la vista radial | `capturas.sh` |

| `07-herramientas.webp` | el menú de herramientas | a mano, dentro de Obsidian |
| `arquitectura.png` | el diagrama de arquitectura | Archify, ver `docs/diagramas/` |

Las cinco del mirador se rehacen con un comando; las tres a mano usan `Modal`, `Setting` y
`Menu`, que son ventanas de Obsidian y no del plugin.

**Todas salen de un vault de ejemplo inventado.** Nunca de un vault real: trae nombres de
clientes en los temas, el nombre de la persona en «Excluir notas» y el nombre del vault en
el título de la ventana. La regla de recorte está en `pruebas/mirador/LEEME.md`.
